## 📜 七、学期末总结叙事模板

### 约束规则
- **开头句**：随机从2句中抽1
- **数据点评**：根据该学期数值变动方向选择对应模板
- **下属动态**：忠诚度变动最大的两位下属触发
- **宠物**：若已收养则追加1句
- **展望句**：随机2选1

#### 拼接逻辑伪代码
```
text = 随机开头句()
text += 经费点评(学期经费变动) + 声望点评(学期声望变动)
text += 士气点评(学期士气变动) + 学生点评(学期学生评价变动)
text += 下属动态(忠诚变动最大的两位)
if 有宠物: text += 宠物彩蛋()
text += 随机展望句()
```

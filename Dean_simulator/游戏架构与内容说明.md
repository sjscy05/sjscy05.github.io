# 《院长模拟器 · V2 月排程版》架构与内容说明

> **文档发布日期**：2026-04-26  
> **代码基线**：V2 月排程制（模块化 ES Module 架构）  
> **对应代码**：`config.js`（游戏配置）、`events.js`（事件素材库）、`game.css`（样式）、`game.js`（引擎逻辑）  
> **HTML 入口**：`deepseek_html_20260426_05064a.html`（加载 CSS + JS 模块）

---

## 1. 项目定位

- **产品形态**：多文件 HTML5 文字策略模拟游戏（模块化 ES Module 架构）。
- **主题体验**：玩家扮演高校系主任/院长，在 8 学期（每学期 3 个月）任期内平衡经费、学术声望、行政信誉、士气、学生评价五大核心数值。
- **核心卖点**：
  - **每月排程制**：玩家在月度布局阶段排定任务，执行阶段以时间线动画逐一展示结果；
  - **事件驱动叙事**：固定学期事件 + 每月随机事件穿插，每次选择都有反馈文本；
  - **下属经营系统**：4 位核心下属各有能力、忠诚、专属任务与缺陷，影响委托执行效果；
  - **开局高度自定义**：6 种院系 × 6 种培养计划 × 3 种难度 × 背景经历选择 × 姓名自定义；
  - **成就与头衔系统**：周目点积累、成就解锁驱动重玩价值；
  - **打字机效果叙事**：所有文本以逐字动画呈现，增强沉浸感。

## 2. 整体技术架构

### 2.1 架构风格

- **架构模式**：模块化前端原生架构，使用 ES Module `import/export` 解耦（V1 单文件 IIFE 已重构为多文件模块）。
- **渲染方式**：基于字符串模板 + `innerHTML` 的手动渲染，无框架依赖。
- **状态管理**：单一全局对象 `v2` 作为状态源（V1 的 `game` 对象已移除）。
- **事件处理**：DOM 事件监听器驱动，使用 `data-*` 属性传递参数，避免 HTML onclick 内嵌 JSON 导致的属性断裂问题。
- **流程控制**：通过阶段标志进行界面分流：
  - `setup`：开局向导（5 步配置向导：序言→院系→培养计划→难度→姓名）；
  - `playing`：月度布局排程（玩家安排日程）；
  - `execution`：执行阶段时间线动画（自动播放事件与行动结果）；
  - `gameover`：结局界面。

## 3. 模块划分（引擎层）

### 3.1 UI 层（展示与交互）

- **容器节点**：`#app`，承载全部动态界面。
- **主要渲染函数**：
  - `v2RenderSetup()`：开局向导（5 步 wizard 流程），绑定 DOM 事件，选择院系/培养/难度/姓名。
  - `v2RenderPlaying()`：主游戏界面，包含状态栏、学期阶段标签、事件区域、行动排程面板。
  - `v2RenderGameOver(text, title)`：结算界面。
- **辅助 UI 函数**：
  - `v2RefreshStatsBar()`：更新顶栏数字区域 + 数值变化动画（stat-flash-up/down）。
  - `v2RenderSchedule()`：渲染排程队列（显示已安排的日/月行动）。
  - `v2RenderActionButtons()`：渲染可选的日常行动按钮（当日/当月的可执行选项）。
  - `v2RenderStaffPanel()`：管理层面板展开/收起。
  - `v2RenderAchievements()`：成就界面弹窗。
  - `v2ToggleStaff()` / `v2ShowAchievements()`：折叠面板切换。
- **执行阶段渲染**：
  - `v2StartExecution()`：进入执行阶段（全屏沉浸式 UI，进度点指示器）。
  - `v2StepExecution()`：执行下一步（推进时间线，显示事件/行动结果）。
  - `v2RenderExecutionContent(stage)`：渲染当前步骤内容（事件/行动/旁白）。
  - `v2CompleteExecution()`：执行阶段完成，返回月度结算。
  - `v2RenderMonthlyWrapUp()`：月度结算弹窗（显示数值变化 + 事件回顾 + 评价引用）。
- **事件绑定规范**：所有按钮使用 `data-*` 属性传递参数（如 `data-act-tab`、`data-act-idx`、`data-staff-talk`），通过 `querySelectorAll` + `addEventListener` 统一绑定，避免 `onclick` 中嵌入 JSON 导致的 HTML 属性断裂。

### 3.2 规则层（数值与结局）

- **数值边界控制**：`v2UpdateStats()` + `clamp()`。
  - 经费：`[-20, 100]`
  - 学术/行政/士气/学生评价：`[0, 100]`
- **数值应用**：`v2ApplyEffect(effect)` 统一处理对象式数值变更，带别名兼容（`effect.reputation` 映射到 `academicRep`）。
- **结局判定**：`v2CheckEndings()` 在关键节点执行即时失败/成功判断：
  - 财务危机（经费过低）；
  - 众叛亲离（士气过低）；
  - 高升结局（学术+经费双高）；
  - 撤并结局（行政+学术双低）；
  - 桃李满天下（学生、士气、学术多高）。
- **通用结束函数**：`v2EndWithMessage(msg, title)` 统一切到 `gameover`。

### 3.3 内容层（事件与文本）

- **事件系统重构**：从 V1 的 `fixedEvents` 数组演进为多池分发的异步事件系统：

  | 池 | 文件名 | 说明 |
  |----|--------|------|
  | `GENERIC_RANDOM_EVENTS` | `events.js` | 通用月度随机事件（每月必触发 1 次） |
  | `REAL_UNIVERSITY_EVENTS` | `events.js` | 大学真实事件专题（更长的叙事，多阶段选择树） |
  | `PET_EVENTS` | `events.js` | 宠物相关趣味事件 |
  | `STUDENT_INTERACT_EVENTS` | `events.js` | 学生互动小事件 |

- **事件结构**：标准化为 `{ title, text, choices: [{ text, days, effect, feedback, ...extra }] }`。
- **事件辅助函数**：`choice(text, days, effect, feedback, extra)` 快速创建选项。
- **评论池**：`STUDENT_COMMENTS`、`TEACHER_COMMENTS`、`LEADERSHIP_COMMENTS` 正/负评论池，用于月度结算随机引用，增强氛围。
- **叙事构建**：`buildTermEndNarrative()` 函数动态生成学期总结文本。

### 3.4 角色层（下属系统）

- **下属生成**：`v2InitStaff()` 在开局时从 `STAFF_TEMPLATES` + `STAFF_PERSONA_POOL` 随机生成 4 位下属：
  - 教学委员会主任（`teach_director`）
  - 学术委员会主任（`acad_director`）
  - 教务办主任（`admin_director`）
  - 实验室主任（`lab_director`）
- **每个下属属性**：
  - `ability`（能力 0-100）
  - `loyalty`（忠诚 0-100）
  - `trait`（性格标签）
  - `profile`（简介）
  - `quest`（专属任务：含标题、描述、效果、忠诚加成）
  - `flaw`（缺陷定义）
- **特殊机制**：`使用 StaffAbility(staffId, statName, maxBonus)` 根据 `(忠诚 + 能力) / 200` 计算效果系数。
- **关系经营**：`v2StaffTalk(idx)` 与下属谈心，消耗精力提高忠诚 → 影响后续"放权型"选项收益。

## 4. 游戏循环（Core Loop）

1. **开局配置（Setup）**
   - 5 步向导：序言 → 选择院系（6 个） → 培养定位（6 种） → 难度（3 种） → 输入姓名
   - 获得初始数值修正 + 随机生成 4 位下属
2. **进入月度排程（Playing）**
   - 显示本月初状态、剩余天数、可用行动
   - 玩家从现有行动池中选择任务排入日程队列
   - 可选的日常行动（按当前周/月阶段不同） + 下属谈心 + 重点课题
3. **执行阶段（Execution）**
   - 播放时间线进度指示器（圆点序列）
   - 依次触发：月度随机事件 → 排程行动执行 → 随机教师/学生评论 → 上级反馈
   - 每一步播放打字机动画叙事文本
   - 数值变化以 Toast 动画实时显示
4. **月度结算（Monthly Wrap-Up）**
   - 展示本月数值变化汇总
   - 随机引用教师/学生/上级评价
   - 触发结局检测（`v2CheckEndings()`）
5. **下月推进**
   - 重置精力/天数，月份 +1
   - 若该学期 3 个月完成 → 学期结算培养计划被动加成 → 学期 +1
6. **任期结束/提前结局**
   - 第 9 学期初触发任期结语
   - 任意时刻触发失败/成功结局

## 5. 关键系统说明

### 5.1 院系选择差异化（6 个院系）

| 院系 | 图标 | 初始修正 |
|------|------|---------|
| 数学系 | 📐 | 学术 +6，经费 -6 |
| 物理系 | 🔭 | 学术 +2，行政 +1 |
| 计算机系 | 💻 | 经费 +10，学生 +3，学术 -2 |
| 文学院 | 📚 | 士气 +6，学生 +4 |
| 经管学院 | 💹 | 经费 +8，行政 +3，士气 -1 |
| 生医学院 | 🧬 | 学术 +5，经费 -10 |

### 5.2 培养计划被动成长（6 种）

| 计划 | 每学期效果 |
|------|-----------|
| 理论扎实 | 学术 +2 |
| 应用技能 | 学生评价 +2 |
| 均衡培养 | 学术 +1，学生 +1 |
| 研究导向 | 学术 +3，经费 -1 |
| 产教融合 | 经费 +2，学生 +2，行政 +1 |
| 国际化 | 学术 +1，学生 +2，行政 +1 |

### 5.3 难度预设（3 种）

| 难度 | 初始修正 |
|------|---------|
| 标准开局 | 无 |
| 地狱开局 | 经费 -15，士气 -8，学生评价 -6 |
| 顺风开局 | 经费 +12，学术 +4，行政 +4 |

### 5.4 精力经济（行动资源）

- 精力是每月核心资源，决定可排程行动数量
- 高收益选项通常高耗能，鼓励取舍与节奏规划
- 月切换时精力重置为 100
- 与 V1 不同的是：V2 引入了"天数"（基础 28 + 2 天），行动消耗天数而非精力点数

### 5.5 关系系统

- 6 个外部关系角色：校长、家人、兄弟院系、学生代表、校友会、合作企业
- 每个关系有 `favor`（好感 0-100）
- 通过事件选项和排程行动调整关系值
- 影响结局判定和特殊事件触发

### 5.6 存档系统

- **元数据持久化**：`v2MetaLoad/Save()` 在 `localStorage` 存储周目点、成就、解锁状态
- **游戏存档**：`v2SaveGame/LoadGame(slot)` 支持 1 个自动档 + 3 个手动档
- **自动存档**：学期切换时自动保存

### 5.7 成就与头衔

- **成就系统**：`v2CheckAchievements()` 在运行时检测成就条件，解锁后通过 Toast 通知：
  - 铁三角团队（核心下属忠诚均 >80）
  - 三连涨（连续三学期学生评价提升）
  - 逆风推进（经费 <10 仍完成重点项目）
- **头衔系统**：`v2UnlockTitles()` 根据状态自动授予称号（改革先锋、拉赞助能手、最受爱戴院长）
- **周目点**：成就点数持久化，跨周目累计

### 5.8 叙事增强

- **打字机效果**：`v2TypeWriter(el, text, speed, callback)` 逐字打印，支持光标闪烁动画
- **执行阶段进度指示**：圆点序列标记事件/行动/评论/旁白进度
- **数值 Toast**：`v2ShowStatToast(delta, statName)` 数值变化飘字动画
- **评论区**：结算时随机引用教师/学生/上级的评价，增强沉浸感

### 5.9 办公装饰系统

- 3 种装饰：咖啡机（+2 日/月）、题字字画（+士气）、小型会客区（+行政 +企业关系）
- 消耗经费和天数购买，提供被动增益

## 7. 代码层可维护性评价

### 7.1 优点

- **模块化架构**：V1 单文件 IIFE → V2 `config.js` / `events.js` / `game.js` 三模块解耦，职责清晰；
- **事件数据标准化**：统一 `{ title, text, choices[] }` 结构，新增事件只需补充数组项；
- **配置与逻辑分离**：院系、培养、难度、下属池等硬编码配置全部下沉到 `config.js`，便于策划调整；
- **存档系统完善**：支持多档位、元数据持久化；
- **视觉增强**：像素风格统一、打字机动画、数值变化反馈、执行阶段沉浸式 UI；
- **DOM 事件规范化**：`data-*` 属性 + `addEventListener` 取代内联 `onclick`，解决了 JSON 嵌入 HTML 属性断裂的 Bug。

### 7.2 局限

- **渲染仍耦合**：`game.js` 中字符串模板与业务逻辑高度混合，~1340 行单文件仍显臃肿；
- **事件数据硬编码**：事件内容仍在 `events.js` 中，未拆到独立 JSON，策划无法独立编辑；
- **缺少 E2E 测试**：全部回归依赖手动试玩；
- **部分 UI 存在 CSS 重复**：`game.css` 中有少量重复定义，偶有属性覆盖问题；
- **执行阶段速率不可调**：打字机速度固定，缺少跳过动画/加速功能；
- **数值平衡缺少工具**：暂无平衡性调试面板或日志导出能力。

### 7.3 已修复问题（基于 V1→V2 迁移和代码审查）

| 问题 | 描述 | 修复方式 |
|------|------|---------|
| 活动按钮不可点击 | `onclick` 中 JSON 含单引号/空格导致 HTML 属性断裂 | 改用 `data-act-idx` + `addEventListener` |
| 管理层/成就链接无视觉框 | 纯文本链接叠在状态栏上不可见 | 新增 `.top-link-btn` CSS 类：边框+背景+hover |
| CSS 重复定义 | 多段 `.staff-panel` / `.staff-card` 定义冲突 | 清理重复，保留完整版本 |
| 单文件过大 | V1 全部塞在单 HTML 中 | 重构为 ES Module 多文件架构 |

## 8. 建议的下一步演进方向

### 8.1 短期（内容扩写）

- **[内容工程化]** 将事件、角色、结局拆到外部 JSON 文件，通过 `fetch()` 加载，策划可独立编辑；
- **[事件扩充]** 增加随机事件池到 30+ 条，学期事件覆盖每学期至少 2 个；
- **[下属增强]** 增加下属性格冲突、离职风险、升职线等纵深玩法。

### 8.2 中期（体验优化）

- **[跳过/加速]** 执行阶段增加"跳过动画"和"2x 速度"按钮；
- **[平衡仪表盘]** 学期结束时显示雷达图/趋势图，辅助玩家理解决策后果；
- **[事件回溯]** 增加行动日志面板，回顾本学期所有决策；
- **[响应式优化]** 当前手机端适配有限，需要适配更小屏幕。

### 8.3 长期（系统深化）

- **[教师队伍系统]** 教师招聘、职称晋升、科研团队形成；
- **[科研项目链]** 多阶段项目树（申请→执行→结题→产业化）；
- **[学生群体画像]** 学生类型分布、满意度细分、毕业去向追踪；
- **[难度解锁]** 通关后解锁隐藏难度或特殊开局背景；
- **[模组支持]** 允许社区编写自定义事件 JSON 并加载。
